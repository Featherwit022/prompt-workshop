# 提示词工坊（Prompt Workshop）

一个 AI 办公助手（千问工作助理）的技能包：把模糊需求变成一条高质量、可直接发给 AI 的提示词，同时附带可复用模板与调优建议。

## 它能做什么

- **生成提示词**：描述你的需求，产出一条"复制即可发送"的成品提示词。
- **优化提示词**：贴出现有提示词，先诊断（歧义、缺失槽位、结构混乱、工具不匹配），再重写并逐条说明改动原因。
- **双份交付**：每次同时给出成品提示词 + 带 `{占位符}` 的可复用模板。
- **工具适配**：支持面向 ChatGPT / Claude / 千问等对话类产品，Cursor / Copilot 等 IDE 类，以及 Claude Code / Codex 等编程 Agent 的风格调整。

## 如何安装使用

1. 下载本仓库（或仅下载 `SKILL.md`）：

   ```bash
   git clone https://github.com/Featherwit022/prompt-workshop.git
   ```

2. 把技能文件夹（内含 `SKILL.md`）放入千问工作助理的技能目录：

   - Windows：`%LOCALAPPDATA%\Qianwen\User Data\qwen-agent\<你的实例ID>\skills\`
   - 或在千问工作助理中使用技能导入功能，选择本仓库目录（`dirPath` 方式，顶层含 `SKILL.md`）。

3. 重启或刷新会话后，直接对助理说：

   - "帮我写个提示词：……"
   - "优化这条提示词：……"
   - "把这段需求变成发给 Cursor 的 prompt"

   助理即会按技能定义走"轻审 → 骨架组装 → 双份交付 → 调优建议"流程。

## 设计要点

- 成品提示词绝不留未解释的空洞：要么填上合理内容，要么做成带说明的 `{占位符}`。
- 不替用户编造事实性上下文；信息缺失时一次问完（≤4 题），禁止连环追问。
- 优化场景必须"为什么改"与"改成什么"同时给出。
